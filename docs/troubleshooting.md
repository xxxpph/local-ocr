# 故障排查手册

按症状查找。排查通用入口：项目根目录的 `logs/server.log`（服务运行日志）与 `install.log`（安装日志）。

## 1. 安装阶段

### 1.1 双击 install.bat 无反应 / 窗口一闪而过
- **杀毒软件拦截**：360/Defender 可能拦截下载的 Python 安装包或脚本执行，选择"允许"
- **路径问题**：确认解压路径不含中文与空格（如 `D:\local-ocr`）
- 手动运行看错误：开始菜单搜索 PowerShell，执行
  ```powershell
  cd D:\你的路径\local-ocr
  .\scripts\install.ps1
  ```

### 1.2 报错 `python.exe : Traceback...` / `NativeCommandError`
- 已修复（v1.0.1+）：detect_env.py 输出强制 UTF-8 + install.ps1 兼容 PS5.1
- 仍出现时：查看 `install.log` 中"检测脚本输出异常，原始输出如下"部分，把内容反馈给开发者

### 1.3 下载很慢 / 卡住
- 依赖默认走官方 PyPI，失败自动切换清华镜像
- GPU 版需下载约 2GB CUDA 运行库（仅首次），耐心等待或改用 CPU 版
- 检查网络代理：若使用代理软件，确认系统代理设置正常

### 1.4 提示驱动过旧（需 >= 560.28）
- 安装会继续走 CPU 版，服务可用但无 GPU 加速
- 更新驱动：https://www.nvidia.cn/drivers/ 后删除 `.venv` 重新运行 install.bat

### 1.5 安装成功但自测失败
- 看自测输出与 `logs/server.log`；常见：
  - 模型目录缺失/损坏 → 重新解压发布包
  - GPU 显存不足 → 自动降级 CPU（提示"GPU 未生效"），可继续使用
  - 杀软隔离了模型文件 → 恢复文件并加入白名单

## 2. 启动阶段

### 2.1 双击 start.bat 后浏览器没自动打开
手动访问 `http://127.0.0.1:8866/`（端口以黑色服务窗口显示为准）。

### 2.2 端口被占用
start.bat 自动探测并 +1（8866 → 8867 → …），无需手动处理。
服务窗口标题会显示实际端口。

### 2.3 服务窗口启动后很快消失
- 看 `logs/server.log` 最后几行
- 常见：模型目录缺失（重新解压）、配置文件损坏（删除 config.json 重启）

### 2.4 页面显示"服务未连接"
- 确认黑色服务窗口还开着（关闭窗口 = 停止服务）
- 重新双击 start.bat

## 3. 识别阶段

### 3.1 页面提示"无法连接 OCR 服务"
- 服务未启动或已退出 → 重新双击 start.bat
- 浏览器地址端口与服务窗口不一致 → 用服务窗口显示的端口访问

### 3.2 页面提示"识别失败: xxx"
- 看 `logs/server.log` 最后的堆栈
- 常见：
  - `不是有效的图片文件` → 文件格式不支持（试试 PNG/JPG）
  - 显存不足（OOM）→ 换 v5-mobile 档位或降低图片分辨率
  - 大图超时 → 图片过大，适当压缩

### 3.3 识别结果为空（0 行）
- 图片文字太小/太密/对比度低 → 放大文字或提高清晰度
- 旋转/歪斜文本识别率低 → 先旋转正
- 可切换模型档位对比（v6-medium 更准）

### 3.4 识别文本标点有差异（全角/半角、冒号等）
模型自身特性，非故障。

## 4. 性能优化

| 场景 | 建议 |
|---|---|
| CPU 用户感觉慢 | 换 v5-mobile 档位（约快 2 倍）；OpenVINO 加速排期 v1.1 |
| 并发请求多 | config.json 增加 `"engine_replicas": 2`（GPU 且显存充足时） |
| 显存小（4GB） | 保持默认 1 副本，用 v5-mobile |
| 大批量图片 | 建议客户端串行调用 + 本地重试 |

## 5. 卸载与重装

- 双击 `uninstall.bat`（删除 .venv/config/日志，保留模型）
- 彻底重装：uninstall.bat → 删除 models/ 目录 → 重新解压发布包 → install.bat

## 6. 需要反馈给开发者时

提供以下信息（缺一不可）：
1. 版本号（/health 的 version 或文件名后缀）
2. `install.log` 或 `logs/server.log` 的相关段落
3. 系统信息：Windows 版本、显卡型号、驱动版本（`nvidia-smi` 第一行）
4. 操作步骤与现象截图
